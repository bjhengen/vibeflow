# vibeflow v0.1.2 Render Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix vibeflow's three classes of render bugs surfaced in daily use against Claude Code (and other TUI apps): idle-redraw CPU/GPU drain, invisible cursor on empty cells (TUI input boxes), and silently-ignored text attributes (bold/italic/underline/strikeout/inverse/hidden/dim).

**Architecture:** Five focused changes across `window.rs` (dirty-redraw refactor), `render/quad.rs` (cursor-as-own-quad + per-flag attribute rendering), `render/text_engine.rs` (font variants + atlas eviction), `render/cursor.rs` (blink scheduler helper), and `assets/` (3 new JetBrains Mono font binaries). No new render pass — everything flows through the existing `QuadPipeline` + `TabBarPipeline`.

**Tech Stack:** Rust, winit 0.30, wgpu 0.20, cosmic-text 0.12 (`Weight`, `Style`, `Attrs`), alacritty_terminal 0.24 (`cell::Flags`, `CursorShape`, `Term`, `Rgb`), JetBrains Mono OFL fonts.

## Why this ordering

T1 is binary-only (no compile impact). T2 is a pass-through refactor (signature change, all callers use `(Normal, Normal)` — render is identical). T3 (cursor) and T4 (dirty-redraw) are mostly orthogonal to T2 — they touch the cursor-blink path and the event loop respectively. T5-T8 are the user-visible attribute work, broken into shippable chunks. T9 is the safety cap. T10 is verification.

Each task is a single commit. Per-task spec + code-quality dual review per the project workflow.

```rust
    /// Return the `Instant` at which `visible()` next flips state, or `None`
    /// when blink is disabled (`blink_ms == 0`). Used by `WindowApp::about_to_wait`
    /// to schedule the next dirty-redraw without a fixed 100 ms timer.
    #[must_use]
    pub fn next_toggle_at(&self, now: Instant) -> Option<Instant> {
        if self.blink_ms == 0 {
            return None;
        }
        let period = self.blink_ms as u128;
        let elapsed_ms = now.duration_since(self.epoch).as_millis();
        let cycles_so_far = elapsed_ms / period;
        let next_boundary_ms = (cycles_so_far + 1) * period;
        let next_offset_ms = next_boundary_ms - elapsed_ms;
        // Cast back: next_offset_ms <= period (≤ a few hundred ms), fits in u64.
        Some(now + std::time::Duration::from_millis(next_offset_ms as u64))
    }
```

```rust
fn underline_geometry(
    flags: alacritty_terminal::term::cell::Flags,
    cell_w: u32,
    cell_h: u32,
) -> Vec<(f32, f32, f32, f32)> {
    use alacritty_terminal::term::cell::Flags;
    let cw = cell_w as f32;
    let ch = cell_h as f32;
    if flags.contains(Flags::DOUBLE_UNDERLINE) {
        vec![
            (0.0, ch - 3.0, cw, 1.0),
            (0.0, ch - 1.0, cw, 1.0),
        ]
    } else if flags.contains(Flags::UNDERCURL) {
        // Cheap 4-quad zigzag approximation. A true curl would need shader
        // support; this conveys "wavy" at v0.1.2 cost.
        let q = cw / 4.0;
        vec![
            (0.0,      ch - 1.0, q, 1.0),
            (q,        ch - 3.0, q, 1.0),
            (q * 2.0,  ch - 1.0, q, 1.0),
            (q * 3.0,  ch - 3.0, q, 1.0),
        ]
    } else if flags.contains(Flags::DOTTED_UNDERLINE) {
        // Dot every 2 px, 1 px wide.
        let mut out = Vec::new();
        let mut x = 0.0;
        while x < cw {
            out.push((x, ch - 2.0, 1.0, 1.0));
            x += 2.0;
        }
        out
    } else if flags.contains(Flags::DASHED_UNDERLINE) {
        // Dash 3 px on, 2 px off.
        let mut out = Vec::new();
        let mut x = 0.0;
        while x < cw {
            let dash_w = (cw - x).min(3.0);
            out.push((x, ch - 2.0, dash_w, 1.0));
            x += 5.0;
        }
        out
    } else if flags.contains(Flags::UNDERLINE) {
        vec![(0.0, ch - 2.0, cw, 1.0)]
    } else {
        Vec::new()
    }
}
```

Order matters: DOUBLE / UNDERCURL / DOTTED / DASHED / single UNDERLINE — the variant flags take precedence over the bare UNDERLINE flag (alacritty may set both).

```rust
/// flooding) can otherwise grow the atlas without bound. At 4096 px tall and
/// the current 256 px wide, the atlas is ~16 MB R8Unorm. Above this cap the
```

```rust
    fn allocate_mono(&mut self, w: u32, h: u32) -> (u32, u32) {
        // Existing shelf-pack logic decides whether the glyph fits.
        // If it doesn't, the legacy path calls grow_mono_atlas; we intercept
        // here to check the cap first.
        if !shelves_can_fit(&self.shelves, self.atlas_w, self.atlas_h, w, h) {
            let new_h = double_until_fits(self.atlas_h, h, &self.shelves);
            if new_h > MAX_MONO_ATLAS_DIM {
                tracing::warn!(
                    current_h = self.atlas_h,
                    requested_h = new_h,
                    cap = MAX_MONO_ATLAS_DIM,
                    "glyph mono atlas hit size cap; resetting cache",
                );
                self.cache.clear();
                self.shelves.clear();
                self.atlas_h = 256;
                self.atlases_dirty = true;
                // Recreate the underlying texture at 256x256 — see the existing
                // grow_mono_atlas for the exact wgpu calls; the reset path uses
                // the same recreate pattern, just with smaller dimensions.
                self.recreate_mono_texture(256);
            } else {
                self.grow_mono_atlas(new_h);
            }
        }
        shelf_pack(&mut self.shelves, self.atlas_w, w, h)
    }
```
